# SONYRA Site Manager GitHub Audit Export Rule

This repository is used as a readable audit export for SONYRA Site Manager source code.

The root must contain only:
- CODEX_GITHUB_AUDIT_EXPORT_RULE.md
- one current folder named sonyra-site-manager-X.X.X-github/

Do not place plugin source folders directly in repository root.
Do not commit secrets, .env files, keys, node_modules, __MACOSX, .DS_Store, or old release zip archives in the repository root.
